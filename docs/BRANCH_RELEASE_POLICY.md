# Branch and release policy V1

## main
Latest reviewed development storefront baseline.

## Branch examples
- `feat/pdp-size-guide`
- `fix/cart-drawer-focus`
- `content/alma-rios`
- `release/prelaunch-01`

## PR rule
Every non-trivial `theme/**` change should go through a PR and official Theme Check.

## Preview
Preview deployment is manual and targets an unpublished theme only.

## Live
No workflow publishes live. Live publication is a human release action after every launch gate is PASS.
