
# Shopify Development Theme — Integration V1

## Combined layers
1. Theme V2 — visual/component layer.
2. Admin Model V1 — metaobjects/metafields.
3. Content + Merchandising V1 — products, variants, collections, navigation, SEO.

## Route completeness
The development theme now covers:
- `/`
- `/products/*`
- `/collections/*`
- `/collections`
- `/pages/creadores`
- `/pages/artistas`
- metaobject artist pages
- metaobject artwork pages
- `/search`
- `/cart`
- `/blogs/*`
- `/blogs/*/articles/*`
- 404
- password page

## Truth boundary
Development theme may render placeholders/editorial seed data. It must not expose physical facts as final until Product Ready passes.
