
# QA release gate

## P1 must all pass
- Navigation to buyable surfaces
- Product variant selection
- Add/remove cart
- Cart/checkout handoff
- Inventory availability
- Product truth/factual claims
- Product Ready
- Payment/shipping/refund E2E

## P2 may not block a controlled soft launch only if explicitly accepted
- Search polish
- Collection index polish
- editorial article polish
- non-critical accessibility/performance improvements

No P1 waiver without Direction owner + documented decision.
